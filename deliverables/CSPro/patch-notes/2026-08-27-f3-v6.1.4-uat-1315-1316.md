## Root cause — #1315

`deliverables/CSPro/cspro_helpers.py::other_specify_procs()`, select-all branch. When no option in a
group literally says "specify", the loose fallback (`_OTHER_LABEL_RE` = `specif|\bothers?\b`) was run
against each row's **whole label**. Every 115.1 row's label begins "115.1 **Other** than the expenses
above…", so every row matched and the first one sorted — `Q1141_1`, Doctor's Professional Fee — captured
the gate. 115.2 was unaffected because its row 7 says "Other (specify)" and the strict `specif` match on
the option text fired first.

Fix (one line + comment): the fallback now tests the **option text after the em-dash** (`_opt_text(k)`),
the same text the strict match uses. `PROC Q1141_OTHER_TXT` regenerates as `if Q1141_6 <> 1 …` /
`if Q1141_6 = 1 and length(strip(Q1141_OTHER_TXT)) = 0 …`. The helper is shared by F1/F3/F4:
regenerating F1 and F4 `.apc` produced **byte-identical** files (md5 `f548f8e8…` / `5272876e…`), so the
fix touches F3 only. `.apc` diff vs the 6.1.2 build = exactly those two lines.

## Root cause — #1316

Stale June-5-era values in `F3/translations/<loc>.json` for `val:PATIENT_TYPE_VS1:1` (FIL/BCL/BIS/CEB/HIL/ILO),
`val:PATIENT_TYPE_VS1:2` (FIL/BIS/HIL/ILO) and HIL `item:Q7_SEX` + `vs:Q7_SEX_VS1`. The Aug-21 check extract
carries **no** value for any of them, and the Aug-21 apply diff never touched them, so the map entry was the
only source. Fix = `"remove": true` entries in `data/translations-official/aug21-overrides.json` (F3 block,
locale-scoped) → `apply_aug21.py --only F3 --extract <task-48 check> --fail-on-pre --apply` removed 11 + 1
keys, strict replay 0/0/0, duplicate-label gate clean. Removal is replayable and blocks any future write to
those keys until an override says otherwise.
