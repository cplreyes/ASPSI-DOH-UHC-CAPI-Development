# aug17-tools

Committed tooling for the Aug-17 CAPI migration (see
`docs/superpowers/plans/2026-08-18-aug17-capi-migration.md`). Scripts here read
paper extracts + build generators and write into the gitignored
`deliverables/CSPro/instruments-aug17-extract/{normalized,maps,reports,status}/`
working area — the scripts are source, their output isn't.

`fixtures/` holds small, committed sample inputs for testing the scripts
themselves (not derived from the NDU-sensitive raw/ questionnaires).
