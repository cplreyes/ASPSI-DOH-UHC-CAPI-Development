Before you analyse

  • Values are raw stored codes — 1 / 2, not Male / Female. The SPSS and Stata files carry the labels embedded; the R files ship with a codebook CSV.
  • Missing values are coded, not blank — categorical items use 8 / 98 for Don't know and 9 / 99 for Refused; amount fields use −98 and −99 so no real amount is ever confused with a refusal.
  • The questionnaire number is a 12-digit string — keep it as text; Excel will otherwise render it as 1.02E+11.
  • Everything is a snapshot of live fieldwork — counts move as tablets sync. Each file carries the timestamp it was generated.
