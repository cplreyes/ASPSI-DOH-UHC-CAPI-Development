1. What was reviewed

  • Two instruments, 149 comments. HCW / F2 (PWA) — 63 comments; Household / F4 (CSPro) — 86 comments. The Facility-Head (F1) and Patient (F3) review documents have not yet been shared; they will get the same treatment when they arrive.

  • XJ rates the CAPI favourably where she could see it — she calls the F2/PWA interface the more polished one (section headers, progress indicators, no repeated question text) and praises the Q35 date design as an improvement over PAPI.

4. The single highest-leverage action

One deliverable clears most of the review: a skip-pattern + validation matrix (keyed to question numbers) plus a test login to the deployed build. That directly answers the recurring "we have no test access / please confirm the skip is programmed / validation not demonstrated" items across both instruments — i.e. the entire bucket C and much of A. The project's verify_questions.py reachability output is the starting point for that matrix. This is preparation for the eventual reply, still gated by the parked decision.

5. Schedule — after pretesting

The remediation is scheduled for the post-pretest window (pretest wraps ~22–24 Jul 2026; LBDH is the last site). Nothing changes on the instruments during fieldwork — a build change mid-pretest would invalidate the very run that tells us which of these findings actually matter. Immediately after pretest, in this order:

  • Consolidate what pretest surfaced — cross the pretest findings against this triage; any XJ item that showed up in the field is promoted from "candidate" to "confirmed."
  • Ship the bucket-C evidence pack — the skip/validation matrix + a test login (the single highest-leverage deliverable; answers most of the review at once).

  • Run the other-specify DCF audit — the ~88 "verify" items, adding a field only where one is genuinely missing.
  • Assemble the consolidated DOH response — one reply covering all 149, ahead of the August training window.

Tracked as a post-pretest epic on the Product Backlog + a milestone on the GitHub trackers (#849 / #850). This is consistent with the park decision — pretest is exactly the gate Dr. Myra named for revisiting the comments.
